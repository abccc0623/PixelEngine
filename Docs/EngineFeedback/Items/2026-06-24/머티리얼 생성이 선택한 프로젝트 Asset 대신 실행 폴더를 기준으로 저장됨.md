## 상황
PixelTool에서 새 프로젝트를 열어 `Create > Material`로 머티리얼을 하나 만들어 두고, 곧바로 Asset 창에서 방금 만든 파일을 확인하려고 했다. 프로젝트 루트는 시작 창에서 따로 고를 수 있으니, 생성 결과도 현재 선택한 프로젝트 아래에 생길 것이라고 기대하게 된다.

## 문제
`MaterialWindow.xaml.cs`는 저장 경로를 `./Asset/{FileName}.mat`로 고정하고, 텍스처 선택 시작 위치도 `AppDomain.CurrentDomain.BaseDirectory/Asset` 기준으로 잡고 있다. 반면 다른 에디터 기능은 `ProjectPathService.AssetPath`를 기준으로 움직인다. 그래서 실행 파일 위치와 현재 프로젝트 루트가 달라진 상태에서는 머티리얼이 선택한 프로젝트가 아니라 프로그램 실행 폴더 쪽 Asset에 저장될 수 있고, 사용자는 Asset 창에서 파일이 안 보이는 이유를 다시 경로 추적으로 찾아야 한다.

## 제안
머티리얼 생성과 텍스처 선택 모두 `ProjectPathService.AssetPath`를 기준으로 통일하는 편이 낫다. 저장 후에는 상대 경로를 현재 프로젝트 Asset 기준으로 계산해서 기록하고, 잘못된 루트에 저장될 수 있는 경로는 UI에서 아예 만들지 않게 막아 두면 자산 생성 흐름이 훨씬 예측 가능해진다.
