## 상황
툴바의 Scene 버튼을 열면 `Save Scene`과 `Load Scene` 메뉴가 따로 보여서, 씬 편집 후 바로 저장하거나 다시 읽어 오는 흐름을 기대하게 된다. 특히 에디터를 처음 쓰는 입장에서는 이 메뉴가 현재 씬 관리의 공식 진입점처럼 보인다.

## 문제
하지만 `ToolbarWindow.xaml`에서 두 버튼은 실제로 노출되어 있고, 연결된 `ToolbarWindow.xaml.cs`의 `SceneSave()`와 `LoadScene()`는 비어 있다. 사용자는 메뉴를 눌러도 아무 반응이 없어서 자신이 잘못 눌렀는지, 씬 시스템이 아직 없는지, 저장이 백그라운드에서 된 건지 판단할 근거가 없다. 존재하는 UI가 기능 상태를 과하게 암시하는 셈이다.

## 제안
기능이 아직 준비되지 않았다면 버튼을 숨기거나 `준비 중` 안내를 분명히 띄우는 편이 낫다. 반대로 최소 기능이라도 연결할 계획이라면 현재 열린 씬 경로, 저장 성공 여부, 불러오기 실패 이유를 메시지로 보여 주는 기본 흐름부터 먼저 붙여 두는 것이 좋다.
