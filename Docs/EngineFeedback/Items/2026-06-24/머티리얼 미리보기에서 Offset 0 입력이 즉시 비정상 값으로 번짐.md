## 상황
머티리얼 창에서 텍스처 타일링을 맞추다가 Offset 값을 0으로 잠깐 바꿔 보며 기준점을 확인하고 싶었다. 이런 값 조정은 미리보기를 보면서 0, 0.5, 1 같은 숫자를 빠르게 오가는 식으로 자주 하게 된다.

## 문제
`MaterialWindow.xaml.cs`의 `UpdateMaterialPreview()`는 오프셋을 `1.0f / offsetX`, `1.0f / offsetY`로 바로 변환한다. 입력 검증은 숫자인지만 확인하고 0은 막지 않기 때문에, Offset에 0을 넣는 순간 미리보기가 무한대나 비정상 변환에 기대어 튀는 상태가 된다. 사용자는 텍스처가 잘못된 건지, 미리보기만 깨진 건지 구분하기 어렵고, 숫자 조정 자체가 불안정하게 느껴진다.

## 제안
Offset과 Tiling 입력은 0을 허용하지 않도록 UI에서 바로 보정하거나, 0을 넣었을 때는 경고와 함께 마지막 유효값으로 되돌리는 편이 낫다. 미리보기 계산식도 실제 엔진의 머티리얼 해석 규칙과 동일한 범위 검증을 거치게 맞추면, 에디터에서 본 결과를 런타임에서 다시 의심하지 않아도 된다.
