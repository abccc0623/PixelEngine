## 상황
엔진 로그를 읽다가 중요한 한 줄만 복사해 메모장이나 이슈 문서에 붙여 넣는 흐름을 떠올리며 `PixelTool/Tool/ConsoleWindow/ConsoleWindow.xaml.cs`를 확인했다. 로그 뷰는 에러를 훑어보는 시간이 길고, 그 사이 다른 창에서 복사해 둔 경로나 코드 조각을 같이 쓰는 경우가 많다.

## 문제
현재 `EngineLogView_SelectionChanged`가 바로 `Copy()`를 호출하고, `Copy()`는 선택만 바뀌어도 클립보드를 덮어쓴다. 사용자는 로그를 읽으려고 방향키나 마우스로 움직였을 뿐인데, 직전에 복사해 둔 파일 경로나 코드가 조용히 사라진다. 로그를 확인하는 단순 탐색 동작과 명시적 복사 동작이 붙어 있어 편집기 전체 복사 흐름을 자주 끊는다.

## 제안
자동 복사는 제거하고 컨텍스트 메뉴나 `Ctrl+C`에서만 복사되게 나누는 편이 안전하다. 필요하다면 더블클릭 복사나 별도 "로그 복사" 버튼을 두되, 선택 자체는 읽기 전용 탐색으로 남겨 두면 다른 창과 오가는 작업 흐름이 훨씬 안정적이다.
