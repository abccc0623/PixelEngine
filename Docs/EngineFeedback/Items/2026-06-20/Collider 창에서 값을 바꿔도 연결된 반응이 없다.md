폐기 사유: ColliderWindow 창은 추후 이렇게 하면 좋지않을까 라는 코드가 들어간 테스트 코드이다.
미완성인 이슈 현재는 Layer 창만 사용하는중

## 상황
에디터에서 충돌체 값을 조정하는 작업 흐름을 보려고 `PixelTool/Tool/ColliderWindow/ColliderWindow.xaml.cs`를 열어 어떤 입력이 엔진 데이터로 이어지는지 확인했다. 박스 크기나 오프셋을 바꾸며 즉시 반영되는 편집 경험을 기대한 상황이다.

## 문제
현재 코드에는 `OnVectorChanged` 핸들러만 있고 내부 구현이 비어 있다. 사용자는 숫자 필드를 바꿔도 실제로 무엇이 저장되거나 반영되는지 알 수 없고, 나중에 씬을 다시 열어봐야만 변경 유무를 확인하는 불안정한 편집 흐름이 된다.

## 제안
변경 이벤트에서 현재 선택 오브젝트의 콜라이더 데이터와 연결되는 최소 반영 경로를 먼저 만들면 좋겠다. 값 적용, 저장 필요 상태 표시, 엔진 프리뷰 갱신 중 무엇이 되는지 로그나 시각 피드백으로 바로 보여주면 에디터 사용성이 크게 좋아진다.
