## 상황
렌더링 파이프라인 쪽을 읽다가 `PixelGraphics/ShaderLoader.cpp`에서 HLSL을 어떻게 불러오는지 확인했다. 셰이더 파일을 수정한 뒤 바로 다시 실행하며 어떤 파일이 깨졌는지 빠르게 확인하고 싶은 흐름을 떠올렸다.

## 문제
`D3DCompileFromFile` 호출에서 에러 블롭을 받지 않고 반환값도 검사하지 않아, 컴파일 실패 시 `shaderBuffer == nullptr` 정도만으로 끝난다. 파일명, 엔트리 포인트, 실제 컴파일 로그가 남지 않으니 셰이더 문법 실수나 include 문제를 잡을 때 매번 디버거에 의존해야 한다.

## 제안
컴파일 실패 시 에러 블롭 문자열과 대상 파일 경로를 함께 로그로 남기고, 어떤 셰이더 단계에서 실패했는지 구분해 주면 좋겠다. 가능하면 실행 중인 워킹 디렉터리와 최종 탐색 경로도 함께 출력해 상대 경로 문제를 바로 분리할 수 있게 만드는 편이 낫다.
