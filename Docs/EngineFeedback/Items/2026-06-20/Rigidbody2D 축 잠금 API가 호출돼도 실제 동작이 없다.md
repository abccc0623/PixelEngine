## 상황
Lua 바인딩에 노출된 물리 API가 실제 구현까지 이어지는지 보려고 `PixelEngine/Rigidbody2D.cpp`를 읽었다. 스크립트에서 회전 잠금이나 축 이동 제한을 걸어 퍼즐 오브젝트를 제어하는 작업 흐름을 상정했다.

## 문제
`LockPosition`과 `LockRotation`은 컴포넌트를 찾아 분기만 하고 실제 Jolt 바디 설정을 바꾸는 코드가 비어 있다. 바인딩 목록에는 기능이 있는 것처럼 보이는데 결과는 무반응이라, 사용자는 스크립트 문제인지 엔진 미구현인지 구분하기 어렵다.

## 제안
지원하지 않는 단계라면 Lua API에서 숨기거나 경고 로그를 내고, 지원할 계획이면 `IsCreate` 전후에 적용할 제약 상태를 저장하는 흐름부터 채우는 편이 좋겠다. 최소한 호출 즉시 미구현 경고를 남기면 물리 디버깅 시간을 크게 줄일 수 있다.
