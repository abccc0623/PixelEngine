폐기 사유: 에디터에서 프로젝트를 새로만들때 관련된 파일들이 모두 생성됨
그 상태에서 에디터는 실행됨 즉 에디터가 열릴때 해당파일들이 없을일 이 없음 

## 상황
새 프로젝트를 열자마자 PixelTool에서 Lua 자동완성을 확인하려고 `PixelTool/Tool/EditorLuaWindow/LuaLspService.cs`와 엔진 생성 흐름을 따라갔다. 에디터를 먼저 띄운 뒤 바로 스크립트를 작성하는 상황을 가정했다.

## 문제
LSP 초기화는 `ProjectPathService.GetEngineFilePath("EngineGenerate.lua")`를 바로 열어 워크스페이스를 준비하는데, 파일이 없으면 오류 로그만 남기고 끝난다. 엔진 생성 파일은 `EditorNotify(GenerateEngineFile)`를 거쳐 만들어지므로 생성 타이밍이 한 번만 어긋나도 사용자는 자동완성, 진단, 전역 심볼이 빠진 빈 편집기를 먼저 만나게 된다.

## 제안
LSP 시작 전에 엔진 생성 파일 존재 여부를 확인하고, 없으면 생성 요청을 먼저 보내거나 생성 완료 후 재초기화하는 단계가 있으면 좋겠다. 적어도 툴바나 시작 창에서 엔진 API 생성 필요 상태를 명시해 왜 자동완성이 비어 있는지 바로 알 수 있어야 한다.
