## 상황
디버그 빌드에서 그래픽 초기화 실패나 리소스 생성 문제를 추적하려고 `PixelSolution/PixelGraphics/GraphicsCore.cpp`의 초기화 경로를 따라갔다.

## 문제
파일 상단에서는 `_DEBUG`일 때 `createDeviceFlags |= D3D11_CREATE_DEVICE_DEBUG;`로 디버그 레이어를 요청하는 것처럼 보이지만, 실제 `D3D11CreateDeviceAndSwapChain(...)` 호출에는 그 값 대신 `0`이 그대로 들어간다. 그래서 개발자는 디버그 빌드라고 생각하고 로그나 Direct3D 진단을 기대하지만, 실제 실행에서는 디버그 레이어가 비활성 상태라 리소스 생성 실패나 상태 오류를 잡기 어렵다.

## 제안
디바이스 생성 호출에 `createDeviceFlags`를 실제로 넘기고, 디버그 레이어 활성 여부를 초기화 로그에 한 줄 남기면 좋겠다. 그래야 렌더 타깃, 깊이 버퍼, 셰이더 생성 문제를 재현할 때 지금 빌드가 진단 가능한 상태인지 바로 판단할 수 있다.
