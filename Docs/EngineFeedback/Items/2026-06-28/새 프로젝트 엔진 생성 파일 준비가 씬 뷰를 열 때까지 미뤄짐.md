## 상황
새 프로젝트를 만든 직후 Lua 편집기, Asset 창, LSP가 바로 쓸 수 있는 상태인지 보려고 `ProjectPathService`와 `GraphicsWindow`의 시작 흐름을 함께 확인했다.

## 문제
`ProjectPathService.CreateProject()`는 `GenerateProjectFilesPending = true`만 세팅하고 끝나며, 실제 `EditorNotify(EditorEventType.GenerateEngineFile, ...)` 호출은 `GraphicsWindow.BuildWindowCore()` 안의 `ProjectPathService.StartNewProject()`에서만 실행된다. 즉 새 프로젝트를 만든 뒤 SceneView를 열지 않으면 엔진 생성 파일 준비가 시작되지 않고, 사용자는 같은 에디터 안에서 어떤 창을 먼저 열었는지에 따라 Lua 자동완성이나 기본 엔진 파일 상태가 달라지는 흐름을 만나게 된다.

## 제안
프로젝트 선택 완료 직후나 메인 창 초기화 시점에 엔진 생성 파일 준비를 명시적으로 실행하고, 아직 준비 중이면 UI에서 상태를 보여주면 좋겠다. 생성 시점이 SceneView 진입 여부에 묶여 있지 않아야 새 프로젝트 시작 경험이 더 일관된다.
