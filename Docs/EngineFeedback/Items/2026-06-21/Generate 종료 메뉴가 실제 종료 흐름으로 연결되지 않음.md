## 상황
Lua API와 JSON 생성기를 번갈아 돌리며 콘솔 도구 사용 흐름을 확인하다가 `PixelSolution/Generate/Generate.cpp`의 메뉴 처리 코드를 읽었다. 생성 작업을 마친 뒤 메뉴에서 종료를 눌러 빠져나오는 동작까지 함께 확인하는 흐름이었다.

## 문제
안내 문구에는 `(4)종료`가 있지만 `switch`에는 `case 4`가 없고, 잘못된 번호를 넣었을 때도 별도 경고 없이 다음 루프로 넘어간다. 콘솔 도구를 반복 실행하는 입장에서는 종료 메뉴가 실제 동작과 맞지 않아 입력이 먹지 않은 것처럼 보이고, 어떤 번호가 유효한지 다시 추측해야 한다.

## 제안
종료 번호를 명시적으로 처리하고, 지원하지 않는 번호를 넣었을 때는 경고와 함께 메뉴를 다시 보여주면 좋겠다. 생성 도구가 단순할수록 메뉴 문구와 실제 분기 동작이 정확히 맞아야 반복 사용이 편해진다.
