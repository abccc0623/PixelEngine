## 상황
서로 다른 프로젝트를 번갈아 열 때 도킹 레이아웃이 어떻게 유지되는지 보려고 `PixelTool/MainWindow.xaml.cs`와 `ProjectPathService.cs`를 같이 읽었다. 프로젝트마다 필요한 창 배치가 다를 수 있으니 레이아웃 저장 위치가 어디인지 확인하는 흐름이었다.

## 문제
현재 레이아웃 파일은 `%LocalAppData%/PixelTool/Layout.xml` 하나만 사용한다. 프로젝트 루트 아래 `Editor` 폴더를 따로 두는 구조와 달리, 실제 레이아웃 상태는 전역 파일 하나에 덮어써져서 다른 프로젝트를 열면 이전 프로젝트에서 쓰던 창 배치가 그대로 섞여 들어온다.

## 제안
레이아웃 저장 경로를 `ProjectPathService.EditorPath` 아래로 옮기거나, 최소한 프로젝트별 파일명으로 분리해 두는 편이 좋겠다. 그래야 프로젝트 성격에 맞는 창 구성을 유지하면서도 현재 설계한 `Asset/Engine/Editor` 폴더 역할과 실제 동작이 맞아 떨어진다.
