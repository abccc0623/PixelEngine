## 상황
새 프로젝트 생성이 아니라 기존 PixelTool 프로젝트를 다시 여는 흐름에서, 엔진 생성 파일이 언제 갱신되는지 코드 경로를 따라갔다.

## 문제
`ProjectPathService.GenerateProjectFilesPending`은 `CreateProject()`에서만 `true`가 되고, 실제 생성 호출은 `GraphicsWindow.BuildWindowCore()` 안의 `StartNewProject()`에서만 돈다. 반면 기존 프로젝트를 여는 `OpenExistingProject()`와 `UseProjectPath()`는 이 플래그를 건드리지 않는데, `LuaLspService`는 곧바로 `Engine/EngineGenerate.lua`를 기대한다. 그래서 기존 프로젝트의 생성 파일이 비어 있거나 오래됐을 때는, 그냥 다시 여는 것만으로는 복구가 자동으로 이어지지 않는다.

## 제안
기존 프로젝트를 열 때도 생성 파일 존재 여부나 버전을 검사해서 필요하면 자동 재생성을 걸고, 최소한 LSP 시작 전에 재생성 안내를 보여주면 좋다.
