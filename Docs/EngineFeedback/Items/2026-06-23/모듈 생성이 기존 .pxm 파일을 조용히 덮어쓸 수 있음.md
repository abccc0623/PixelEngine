## 상황
PixelTool에서 새 모듈을 만들려고 `ToolbarWindow`의 Create 메뉴를 열고, 이미 있는 모듈과 같은 이름을 다시 입력하는 작업을 했다.

## 문제
`ToolbarWindow.CreateModule()`은 중복 검사를 할 때 확장자를 붙이기 전 경로만 검사하고, 실제 저장은 그 뒤에 `.pxm`을 붙여서 진행한다. 그래서 `Player`를 입력했을 때 `Player.pxm`이 이미 있어도 경고 없이 같은 파일을 다시 써버릴 수 있어, 사용자는 새 파일을 만든 줄 알았다가 기존 모듈 내용을 잃기 쉽다.

## 제안
입력 이름을 받는 즉시 실제 저장 파일명까지 정규화해서 중복을 검사하고, 충돌 시에는 최종 대상 경로를 함께 보여주면 좋다.
