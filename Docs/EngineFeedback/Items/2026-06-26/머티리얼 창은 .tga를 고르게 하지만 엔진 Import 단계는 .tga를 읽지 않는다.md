## 상황
머티리얼 창에서 텍스처를 고른 뒤 실제 엔진 import 단계까지 같은 확장자를 일관되게 처리하는지 따라가 봤다.

## 문제
`PixelSolution/PixelTool/Tool/MaterialWIndow/MaterialWindow.xaml.cs`는 텍스처 선택 필터에 `*.tga`를 포함하고, `AssetWindow` 미리보기 쪽도 `.tga`를 이미지로 취급한다. 그런데 `PixelSolution/PixelEngine/PixelEngineAPI.cpp`의 `ImportFile()`은 텍스처 로드를 `.png`와 `.jpg`에만 연결해 둬서, 에디터에서 자연스럽게 고른 `.tga`가 런타임 import 단계에서는 빠질 가능성이 크다.

## 제안
엔진 import 지원 확장자를 `.tga`까지 넓히거나, 아직 지원하지 않는다면 에디터 선택 필터와 미리보기 안내에서 명확히 막는 편이 좋다. 에디터가 허용한 자산이 엔진에서 조용히 누락되는 흐름을 먼저 줄여야 그래픽 작업이 덜 헷갈린다.
