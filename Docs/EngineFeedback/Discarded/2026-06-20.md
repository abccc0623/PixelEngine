### 폐기 사유

## Lua LSP가 엔진 생성 파일 없이는 빈 상태로 시작됨

- 영역: 에디터
- 폐기일: 2026-06-21
- 출처: [[Lua LSP가 엔진 생성 파일 없이는 빈 상태로 시작됨]]

### 피드백 요약
LSP 초기화는 `ProjectPathService.GetEngineFilePath("EngineGenerate.lua")`를 바로 열어 워크스페이스를 준비하는데, 파일이 없으면 오류 로그만 남기고 끝난다. 엔진 생성 파일은 `EditorNotify(GenerateEngineFile)`를 거쳐 만들어지므로 생성 타이밍이 한 번만 어긋나도 사용자는 자동완성, 진단, 전역 심볼이 빠진 빈 편집기를 먼저 만나게 된다.

### 폐기 사유
에디터에서 프로젝트를 새로만들때 관련된 파일들이 모두 생성됨
그 상태에서 에디터는 실행됨 즉 에디터가 열릴때 해당파일들이 없을일 이 없음

## Pool 생성 엔티티가 아직 실제 풀에 등록되지 않음

- 영역: 엔진
- 폐기일: 2026-06-21
- 출처: [[Pool 생성 엔티티가 아직 실제 풀에 등록되지 않음]]

### 피드백 요약
현재 `Scene::CreatePoolEntity`가 `0`을 반환하고 있어, Pool API가 실제 Entity 생성과 Pool 등록까지 이어지는지 확인할 수 없다. 이 상태에서는 Lua 사용자가 Pool을 써도 일반 생성과 어떤 차이가 있는지 알기 어렵다.

### 폐기 사유
개발 진행중인 상태라 아직은 코드가 들어가지 않은상태

## Rigidbody2D 축 잠금 API가 호출돼도 실제 동작이 없다

- 영역: 물리
- 폐기일: 2026-06-21
- 출처: [[Rigidbody2D 축 잠금 API가 호출돼도 실제 동작이 없다]]

### 피드백 요약
`LockPosition`과 `LockRotation`은 컴포넌트를 찾아 분기만 하고 실제 Jolt 바디 설정을 바꾸는 코드가 비어 있다. 바인딩 목록에는 기능이 있는 것처럼 보이는데 결과는 무반응이라, 사용자는 스크립트 문제인지 엔진 미구현인지 구분하기 어렵다.

### 폐기 사유
개발중인 내용이라 발생하는 이슈

## Collider 창에서 값을 바꿔도 연결된 반응이 없다

- 영역: 에디터
- 폐기일: 2026-06-21
- 출처: [[Collider 창에서 값을 바꿔도 연결된 반응이 없다]]

### 피드백 요약
현재 코드에는 `OnVectorChanged` 핸들러만 있고 내부 구현이 비어 있다. 사용자는 숫자 필드를 바꿔도 실제로 무엇이 저장되거나 반영되는지 알 수 없고, 나중에 씬을 다시 열어봐야만 변경 유무를 확인하는 불안정한 편집 흐름이 된다.

### 폐기 사유
ColliderWindow 창은 추후 이렇게 하면 좋지않을까 라는 코드가 들어간 테스트 코드이다.
미완성인 이슈 현재는 Layer 창만 사용하는중
