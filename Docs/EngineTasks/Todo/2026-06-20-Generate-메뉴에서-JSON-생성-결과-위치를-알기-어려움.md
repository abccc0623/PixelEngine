## 배경
Lua API를 갱신하려고 `PixelSolution/Generate/Generate.cpp`의 콘솔 생성기를 돌리며 어떤 옵션이 어떤 파일을 만드는지 확인했다. 메뉴를 보고 LSP용 출력과 JSON 출력을 번갈아 실행해 결과 파일을 비교하려고 했다.

현재 메뉴 텍스트는 2번과 3번이 모두 `LSPGenerate`로 표시되고, 3번 분기에서는 `JsonGenerate(outputPath.c_str())`를 호출하면서 `outputPath`를 채우지 않는다. 생성이 끝나도 사용자는 어떤 파일이 갱신됐는지 바로 알 수 없고, 잘못된 산출물을 읽고 있다고 착각하기 쉽다.

## 작업
메뉴 이름, 분기 번호, 실제 출력 경로를 한 번에 맞춰 보여주고 실행 직후 저장된 파일 경로를 로그로 남기면 좋겠다. JSON과 Lua API 생성 경로를 상수화해 엔진 바인딩을 갱신할 때 매번 코드를 뒤지지 않게 만드는 흐름이 필요하다.

## 완료 조건
- 개선 방향이 코드나 문서로 반영된다.
- Lua/API/에디터 사용자가 변경된 동작을 확인할 수 있다.
