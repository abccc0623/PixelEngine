## 배경
PixelTool 시작 창에서 기존 프로젝트 폴더를 선택했는데 유효하지 않은 프로젝트라는 오류를 만남.

`Asset`, `Engine`, `Editor` 중 어떤 폴더가 없어 실패했는지 알 수 없으면 사용자가 직접 폴더 구조를 뒤져야 한다.

## 작업
검증 결과에 누락 폴더 목록을 포함하고, 시작 창에서 복구 안내나 폴더 생성 버튼을 제공하면 좋음.

## 완료 조건
- 개선 방향이 코드나 문서로 반영된다.
- Lua/API/에디터 사용자가 변경된 동작을 확인할 수 있다.
