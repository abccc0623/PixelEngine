# 코드 변경 결과 보고

엔진·에디터 소스를 수정한 최종 답변에는 다음을 한국어로 짧게 적는다.

- 변경 파일과 각 파일의 실제 변경 사항을 클릭 가능한 절대 경로로 안내한다.
- 새 API나 기능의 사용 방법이 필요하면 최소 예시를 준다.
- 수행한 정적 검사·빌드·실행 검증을 구분하고, 남은 제한이나 재빌드 필요 여부를 알린다.

기존 사용자 변경을 이번 작업의 수정 내역으로 보고하지 않는다. 이 스킬은 추가 수정이나 빌드 권한을 부여하지 않는다.
