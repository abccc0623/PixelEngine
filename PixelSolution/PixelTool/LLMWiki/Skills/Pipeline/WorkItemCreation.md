# 파이프라인: 일감생성

요청 분석 결과가 **신규구현**일 때 읽는다.

요청한 완성품의 일반적인 기능을 레퍼런스로 확인한다. 각 기능을 현재 엔진 API·컴포넌트와 대조해 구현 가능한 범위로 좁힌다. 구현 가능한 기능은 각각 일감으로 정의하고, 필요한 엔진 기능이 없으면 그 사실을 주의사항에 적는다.

사용자에게 다시 묻지 않는다. 요청에 없는 세부 선택은 확인한 레퍼런스와 엔진 기능을 근거로 정하고, 어떤 기준을 택했는지 일감 내용에 적는다.

- 일감마다 256비트 무작위 ID를 만들고, 같은 ID의 파일이 있으면 다시 생성한다.
- 제목, 기능 내용, 주의사항, 검색 키워드를 기록한다.
- 열린 프로젝트의 `Editor/WorkItems/<ID>.md`에 저장한다. 다른 프로젝트의 일감과 섞지 않는다.
- 저장된 일감은 ID, 제목, 키워드, 내용으로 검색하고 원문을 읽을 수 있어야 한다.

AI 챗에서는 `create_project_work_item`으로 저장하고, `search_project_work_items`로 찾은 뒤 `read_project_work_item`으로 원문을 읽는다.
