# PixelEngine Lua API

## Engine.BackgroundColor

### 언제 사용하는지
게임 화면의 기본 배경색을 바꿀 때 사용합니다. `Asset/main.lua`의 `Main()`이나 씬의 `Start()`에서 설정할 수 있습니다.

### 최소 예제
```lua
Engine.BackgroundColor(115, 100, 145)
```

### 주의사항
- 인자는 빨강·초록·파랑 순서의 정수 3개입니다. 각 값은 일반적인 RGB 범위인 0~255로 지정하세요. 알파 인자는 없습니다.
- 화면 배경색을 설정합니다. 객체의 색이나 텍스처는 바꾸지 않습니다.
- 반환값은 없습니다.

## Engine.SetWindowSize

### 언제 사용하는지
PixelTool 밖에서 실행하는 게임 클라이언트 창의 내부 크기를 지정할 때 사용합니다.

### 최소 예제
```lua
Engine.SetWindowSize(1280, 720)
```

### 주의사항
- 인자는 창 내부의 `width`, `height` 순서이며 양의 정수여야 합니다. 값이 32767을 넘거나 유효한 클라이언트 창이 없으면 요청을 무시합니다.
- 크기 변경은 호출 중 바로 실행되지 않고 다음 엔진 업데이트에서 적용됩니다.
- PixelTool 에디터에서는 요청을 무시합니다. 1920×1080 UI 가상 캔버스 크기도 바꾸지 않습니다.
- 반환값은 없습니다.
