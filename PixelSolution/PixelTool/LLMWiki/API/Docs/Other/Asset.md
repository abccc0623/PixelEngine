# PixelEngine Lua API

## Asset

### 언제 사용하는지
Lua 코드나 게임 리소스 파일·폴더를 엔진에 가져올 때 사용합니다.

### 최소 예제
```lua
Asset.Import("./Asset/Script")
```

### 주의사항
- 파일 하나를 지정할 때는 `./Asset/Script/Player.pxm`처럼 확장자까지 포함하세요. 폴더를 지정할 때는 확장자가 필요하지 않습니다.
- 경로가 실제로 있어야 합니다. 데이터와 스크립트의 의존 순서를 명시하세요. 폴더 내부 탐색 순서에 의존하지 마세요.
