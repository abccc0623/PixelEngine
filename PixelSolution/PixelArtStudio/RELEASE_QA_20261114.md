## 코드 문제 근거

배경 제거 후 반투명 픽셀 1,934개가 모두 `원본RGB × alpha` 값으로 저장되어 있었다. PNG의 straight alpha를 다시 합성하면 RGB가 이중으로 어두워질 수 있다. 주황/로봇/검의 원본 RGB 평균 오차는 각각24.078/28.83/126.016이었다.

실행 완료는 리소스 품질 합격과 다르다. 특히 흰 물체의 마스크 정확도, 화면을 채우는 배경, 타일 이음새는 이번 결과로 보장되지 않는다. 수동 원본 보존 및 배경 제거 끄기 선택은 계속 제공한다.

## 적용한 소스 수정과 재검증

- rembg 호출에 `putalpha=True`를 사용해 RGB를 원본 그대로 보존하고 마스크는 알파로만 적용한다.
- 전경(alpha>=128) 비율 5% 미만은 의도한 작은 물체인지/마스크 손실인지 확인하라는 안내를 출력한다. 자동 실패 판정이나 강제 복원은 하지 않는다.
- Python 회귀 테스트 34/34 통과. 빌드/컴파일/publish 없음.
- 기존 원본 3종을 CPU rembg로만 재처리했다. 부분알파 RGB 1,934개 모두 원본 RGB와 정확히 일치했고 알파는 기존과 동일했다. 실제 비교 이미지에서 흰 로봇의 어두워진 색은 개선되었으나 마스크 누락 자체를 복구한 것은 아니다.
- 작은 검은 여전히 전경17픽셀이다. 칼날 삭제, 숲의 외곽 여백, 타일 품질은 해결됐다고 주장하지 않는다.
